# Changelog

This file lists the main changes that affect publishers.

## 1.1.0 — 2026-08-20

- Added support for Firefox.
- Added a dark color theme.
- Kept the selected chart zoom when you use the time range menu.
- Improved the suggested chart interval for the selected time range.
- Fixed the start date used to collect complete account history.
- Opened the Publisher Portal in a new tab when you leave Publisher Analytics+.

## 1.0.0 — 2026-08-18

- Added lifetime sales, revenue, downloads, pageviews, and conversion reports.
- Added custom time ranges and several chart intervals.
- Added dashboard, calendar, revenue flow, and package growth views.
- Added chart and data exports.
